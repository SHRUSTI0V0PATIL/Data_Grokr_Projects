# CLI Student Grade Calculator

A beginner-level Python command-line application that calculates a student's total marks, average, grade, and pass/fail status.

This project was developed as part of the **DataGrokr Pre-Learning Program (PLP) – Week 1 Mini Project**.

---

## 📌 Project Overview

The CLI Student Grade Calculator takes a student's marks in:

- Python
- SQL
- Git

It then calculates:

- Total marks
- Average marks
- Grade
- Pass/Fail status

The project uses core Python fundamentals covered during Week 1.

---

## ✨ Features

- Accepts the student's name
- Accepts marks for Python, SQL, and Git
- Stores subject marks using a dictionary
- Calculates total marks
- Calculates average marks
- Assigns a grade based on the average
- Determines pass/fail status
- Handles invalid average values
- Uses functions to organize calculations
- Provides a simple command-line interface

---
