# OOP Banking System and Transaction Analysis

## Project Overview

This project is a simple command-line banking system
built using Python Object-Oriented Programming.

It supports customers, savings accounts, current accounts,
deposits, withdrawals, transfers, and transaction history.

The transaction history is exported to CSV files and
analyzed using Pandas and NumPy.

## Features

- Customer management
- Savings and current accounts
- Deposit money
- Withdraw money
- Transfer money
- Transaction history
- CSV export
- Pandas analysis
- NumPy calculations
- Custom exception handling

## How to Run

1. Create a virtual environment.

2. Activate the virtual environment.

3. Install dependencies:

   pip install -r requirements.txt

4. Run the project:

   python main.py

## Output

The program generates:

- data/transaction_history.csv
- data/customers.csv
- reports/analysis_report.txt
